# Cozinha da Rô — Landing Page

Landing page responsiva baseada no arquivo de referência **Landing page ro.pdf** (4 páginas).

## Executar
Abra `index.html` no navegador ou use um servidor estático (ex.: Live Server). Não requer build, dependências npm nem backend.

## Estrutura
- `index.html` — conteúdo e seções da página.
- `src/styles.css` — identidade visual e responsividade.
- `src/app.js` — produtos demonstrativos, filtros, navegação mobile e links de WhatsApp.
- `assets/README.md` — orientação para substituir os espaços de imagem.

## Antes de publicar
1. Substituir espaços FOTO/PÔSTER/PRINT por imagens reais autorizadas.
2. Confirmar produtos, descrições, preços e link do cardápio online.
3. Confirmar datas e horários de eventos, promoção da semana e depoimentos reais autorizados.
4. Confirmar a nota do Google, Instagram, horários de funcionamento e endereço.
5. Testar os links do WhatsApp: número configurado `5514997074717`.

Os preços não foram inventados: os cartões mostram **Preço a confirmar**. O botão + consulta o item no WhatsApp, sem simular checkout ou pedido concluído.
